# Real-Time Face Mask Detection

## Overview
This project detects whether a person is wearing a face mask in real time using Python, OpenCV, and Deep Learning.

## Features
- Real-time webcam face detection
- Mask / No-mask classification
- Deep learning based detection
- Live video processing

## Technologies Used
- Python
- OpenCV
- TensorFlow / Keras
- NumPy

## Files
- detect_mask.py → Main detection script
- train_mask_detector.py → Model training script
- mask_detector.keras → Trained model

## How to Run

Install dependencies:

pip install opencv-python tensorflow numpy

Run the project:

python detect_mask.py
